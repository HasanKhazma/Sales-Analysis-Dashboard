# Sales Analysis Dashboard

## Overview

An interactive Power BI dashboard built using DAX, Excel, and data modeling techniques to transform raw sales data into meaningful business insights.

The dashboard focuses on sales performance, customer profitability, product demand, purchasing trends, and business reporting to support data-driven decision-making.

## Key Features

* Sales performance analysis
* Customer profitability analysis
* Product demand and performance tracking
* Purchasing trend analysis
* Interactive visualizations and KPIs
* Business reporting and data storytelling

## Tools Used

* Power BI
* DAX
* Microsoft Excel
* Data Modeling
* Data Visualization
* Business Intelligence

## Project Goal

The goal of this project was to practice transforming raw business data into an interactive analytical dashboard using Power BI, DAX, and data modeling.

The project demonstrates how data can be cleaned, modeled, analyzed, and presented through interactive visualizations to support business understanding and decision-making.
